# Security Policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability, credential exposure, prompt-injection path, unsafe automation, or supply-chain concern. Use the repository's [private security advisory form](https://github.com/digows/agentic-skills/security/advisories/new).

Include the affected path or skill identifier, reproduction steps, impact, and any safe proof of concept. Do not include credentials, customer data, private addresses, or production exports.

## Scope

Reports are welcome for repository tooling, GitHub Actions configuration, published skills, provider adapters, and documentation that could cause unsafe behavior. Static checks reduce risk; they are not a security guarantee.

## Supported versions

Only the current `main` branch is supported while the catalogue is in its foundation phase.
