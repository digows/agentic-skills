# Skills directory

Each published skill is a direct child directory containing the portable `SKILL.md` entrypoint, a `catalog.json` sidecar, and an `evals/definition.json` evaluation definition. Do not place published skills in category subdirectories.

Planned domains are listed in [`../catalog/planned-skills.json`](../catalog/planned-skills.json) until their contracts, safety boundaries, and evaluations are ready.
