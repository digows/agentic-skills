# Skills directory

Each published skill lives under its primary category: `skills/<category>/<skill-id>/`. It contains the portable `SKILL.md` entrypoint, a `catalog.json` sidecar, and an `evals/definition.json` evaluation definition. The category directory must match the `category` in `catalog.json`.

Planned domains are listed in [`../catalog/planned-skills.json`](../catalog/planned-skills.json) until their contracts, safety boundaries, and evaluations are ready.
